마을 AR 보물찾기 — 장소 사진 25장 → 번호에 맞는 캐릭터

[현재 완료된 작업]
- 장소 사진 25장과 대응 캐릭터 파일을 번호 기준으로 연결
- 2번 장소 사진 2개 → 2번 캐릭터, 20_1 장소 사진 2개 → 20_1 캐릭터,
  20_3 장소 사진 2개 → 20_3 캐릭터
- 장소 사진 9번은 없음. 따라서 캐릭터 9번은 이번 프로젝트에 포함하지 않음
- index.html, 이미지, 대상 목록, AR 이벤트 기능 작성

[중요: 아직 해야 할 1단계 - targets.mind 만들기]
이 환경에서는 MindAR의 공식 Image Target Compiler를 실행할 수 없어 targets.mind가 포함되지 않았습니다.
반드시 아래 방식으로 컴파일해야 카메라 인식이 작동합니다.

1) https://hiukim.github.io/mind-ar-js-doc/tools/compile/ 에 접속
2) compiler_photos 폴더 안의 00_...jpg 부터 24_...jpg 까지 25장을
   모두 선택해 업로드. 업로드 후 화면에서 실제 정렬 순서가 00,01,...,24인지 확인
3) Start → Compile 완료 → Download로 .mind 파일 받기
4) 다운로드 파일을 targets.mind로 이름 변경
5) index.html과 같은 위치에 targets.mind 복사
6) 아래 구조의 파일/폴더 전체를 GitHub Pages 저장소 루트에 업로드:

  index.html
  targets.mind                ← 사용자가 만들어 추가하는 파일
  assets/characters/*.webp   ← 이미 포함
  compiler_photos/*.jpg     ← 등록 참고용, 웹 공개는 선택 사항
  places.json               ← 장소 이름/번호 매핑 자료

[주의]
- 25장을 동시에 컴파일할 때 브라우저 메모리 문제나 컴파일 실패가 날 수 있습니다.
- 정확한 순서가 매우 중요합니다. 순서가 달라지면 다른 캐릭터가 나옵니다.
- 모든 사진을 한꺼번에 업로드했을 때 목록이 표시되는 순서를 확인해 주세요.
- 웹 실행은 반드시 HTTPS(예: GitHub Pages)이며 앱 첫 실행 때 카메라 권한 허용.
- 실제 거리/건물/나무 사진은 MindAR 이미지 추적이 불안정할 수 있습니다.
- 본 프로젝트는 GPS 및 사용자 위치 정보를 요청하지 않습니다.
- 현재 수집 현황은 실행 중 탭에서만 유지되며 새로고침하면 초기화됩니다.
- HTML은 외부 A-Frame, MindAR 라이브러리를 CDN에서 로딩하므로 인터넷이 필요합니다.
